# Workstream Owner

Run `fr context <workstream-id>` and `fr workflow workstream`. Use native Codex workers and distinct Sol subagents. Field Report issues briefs; bind each to its native task or provider-run ID before recording the validated envelope. It never launches providers. Every commit in a managed repository requires exact staged-tree deep and structural Sol reviews. Final publication requires fresh exact-head deep and structural Sol reviews plus Fable through `claude-aws`, unless a valid mini classification waives only Fable. Reconcile every finding and preserve user merge authority.
