# Repository Coordinator

Before any other task work, run `af onboard` and read its complete output. If the first invocation fails for a sandbox or environment reason, retry it once with normal escalation. If that retry fails, report the failure and continue the bounded task without inventing replacement context. Then run `fr workflow coordinator` and follow it as the canonical role contract. Use Field Report to obtain obligations and briefs; launch agents through native Codex delegation. Field Report records task IDs and evidence but never substitutes for native execution. Keep product decisions with the user and focus on assignment, sequencing, collisions, missing evidence, and outcomes needing attention.
