Field Report

Settings

Field Report keeps AI coding agents honest about review. Before a pull request opens, three reviewers check the change from three angles, each in a fresh context with no memory of how the work was done. Field Report records each verdict against the exact commit and tells the agent whether the work is ready. It never merges; that stays with you.

Models Projects

Which models review each angle. These apply to every project.

Each seat accepts only the models listed for it. The first is the default; the others are fallbacks, tried in order if the default can't start. Using different models across seats gives different perspectives, but one model may fill every seat.

Launch
Which command-line tool runs the reviewer: codex (OpenAI's Codex CLI), claude (Claude Code), cursor (Cursor's agent CLI), agy (Google's Antigravity CLI), or devin (Devin's CLI). Use whichever you have; several offer models from more than one lab. It must be installed and signed in; fr doctor checks.
Model id
The model's plain name, without a cursor- prefix or an effort suffix like -high. Suggestions come from your Cursor and Antigravity accounts and your config; any id works.
CLI model
Only when the tool expects a different name. Cursor and Antigravity ids usually add an effort level, for example cursor-grok-4.6-high or gemini-4-neon-high.

Repositories Field Report knows, each with where agents file todos and where multi-PR build plans live. Each project saves on its own. Add a repository with fr project add in the terminal. Removing a project also deletes its workstreams and their review records.
